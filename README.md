# Vishwas Bhatia — Salesforce Portfolio

A modern, responsive, single-page Salesforce Administrator portfolio.

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository named `vishwasbhatia.github.io`.
2. Upload `index.html` and `Vishwas_Bhatia_Salesforce_Admin_Tailored_CV.pdf`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your portfolio will be available at `https://vishwasbhatia.github.io/`.

No paid hosting is required.
